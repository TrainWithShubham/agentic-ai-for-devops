# DevOps in the agentic AI era


Next / learning choices


## In everyday words

DevOps skills still matter. AI adds work: using agents, operating AI applications and building platforms that control how agents act.


## Picture it

Several roads can start from the same town. Choose the route that fits the work you want to do.

These fields overlap. The roads show learning choices, not separate teams or guaranteed jobs.



**Use AI.** Investigate and prepare changes.


**Operate AI.** Check quality, cost and reliability.


**Build platforms.** Give people and agents safe tools.


## Four names, different jobs

AIOps uses AI for operations. MLOps and LLMOps operate AI systems. Agent operations adds control over tool choices and actions.


### Diagram reading order


1. **AIOps:** AI for IT operations: connect alerts, spot unusual behavior and help investigate incidents.

2. **MLOps:** Operate machine-learning models and data pipelines: train, version, deploy and watch for changes in data and model performance.

3. **LLMOps / GenAIOps:** Operate language-model apps: version prompts, refresh RAG, evaluate answers and monitor cost.

4. **Agent operations:** Operate tool-using agents: identity, approvals, budgets, recovery and action records.



Fields overlap. GenAIOps can cover non-language models too. Agent operations is a descriptive label here. AIOps can use predictive ML without an agent.


## Your next project, one step at a time

Example: a CI helper that reads evidence and prepares a fix for review. Add responsibility as your checks improve.



1. **Keep the foundations:** Linux, networking, Python, Git, cloud, IAM and CI/CD.

2. **Use one agent well:** Inspect a small patch, its evidence and the actual check results.

3. **Operate the helper:** Add evaluation gates, traces, scoped tools, cost limits and rollback.

4. **Choose a direction:** AIOps for incidents; AI platforms for shared tools; MLOps for model pipelines.



A learning direction for 2027, not a hiring forecast. Show a failed dependency, a denied action and a verified result in your next project.
