# Troubleshooting

## Python or installation problems

Run from the repository directory, which contains `pyproject.toml`. Use `uv sync --frozen`. The project selects Python 3.12 and supports 3.11 through 3.13. The old course and its separate setup are on `v1`; `v2` uses the locked uv environment.

If a managed workplace laptop blocks installs, use the supplied devcontainer or GitHub Codespaces. Codespaces account allowances and model API limits are separate.

## API key or model problems

Keep `OPENROUTER_API_KEY` in `.env`, not in Python source. Claude Pro login does not fund application API calls. An API key belongs to one learner; creating more keys under one account does not multiply the quota.

Use `uv run runbookops models` to check the current free tool-capable catalog. The initial tested candidate is `nvidia/nemotron-3.5-lightning:free`, checked on November 11. It may change or become unavailable. Recheck it before the event.

A 401 response usually means the key is invalid or unavailable to the selected process. A 429 means a rate or quota limit was hit. A 404 or provider error may indicate the model is no longer available. Stop retries, inspect the provider dashboard, then explicitly select the tested backup or use offline practice. The application never silently switches to a paid model.

With a key configured, run `uv run python scripts/check_openrouter.py --env-file .env --model nvidia/nemotron-3.5-lightning:free`. This uses two model calls and is separate from the full capstone.

## TLS certificates

Some Python distributions on macOS do not use the system CA bundle automatically. The standard-library smoke script adds `/etc/ssl/cert.pem` when present. You can also set `SSL_CERT_FILE` to a trusted CA bundle supplied by your organization. Never disable certificate verification.

A certificate error is different from a DNS error. Check the error message and use the provider's public model catalog to distinguish connectivity from inference authorization.

## No proposal was prepared

Inspect the incident trace and the `error` field. Preparation requires observed health, logs, deployments, and the current checkout runbook. Evidence entries must be exact retrieved source/tool IDs. The executor intentionally rejects a plausible fix with invented references.

If a free model repeatedly chooses the wrong tool arguments or exhausts the model-call budget, save the trace and use a fresh offline incident to continue the lesson. Do not increase limits indefinitely. The diagnosis summary after proposal preparation is generated by the application from the validated proposal and is labeled as such.

## Embedding download or retrieval issues

Hash mode works without downloading a model, but uses lexical feature hashing. Use `--embedding semantic` for real semantic embeddings. Download before class with `uv run runbookops --embedding semantic index`; the download can take several minutes on a slower network.

Use the same embedding mode when indexing and searching. A content, metadata, or embedding change creates a new versioned collection. `index --rebuild` rebuilds the selected collection. Superseded and unauthorized sources are filtered regardless of similarity.

PDFs must have extractable text for this lab. Scan/OCR, complex tables, image-based diagrams, legacy PPT, and speaker-note extraction are separate extensions. The supplied fixtures are tested text-based examples. Source locations in DOCX are paragraphs/tables, not fabricated page numbers.

## Approval problems

Put `--as jethalal` before the `approve` subcommand. Review and supply the exact stored proposal hash. Approval expires after 15 minutes. A changed service revision, expired proposal, mismatched hash, or repeated decision is rejected.

Each `investigate` creates an isolated incident. `status INCIDENT_ID` loads an existing one. `resume INCIDENT_ID` is for a previously stored approval decision whose graph execution was interrupted. The demo exercises restart/resume for you.

## MCP problems

Run `uv run python examples/mcp_client.py`. It launches the server using the same Python executable and absolute script path, avoiding the previous course's working-directory dependency. The subprocess receives only workshop settings, not model API credentials.

For HTTP transport, the token subject must be a known user, and it must contain the required scope. A valid signature alone is not enough. Keep tools bound to the authorized incident.

## Test and deployment problems

`uv run pytest -q` exercises the local app. For mocked DynamoDB checkpoint tests, install extras with `uv sync --extra aws` and rerun. `uv run runbookops evaluate` runs the small deterministic scenario set without testing live model quality.

The instructor image must target Linux ARM64. The deployment record is under `.state/aws-deployment.json`. If Runtime creation fails after tables or the image were created, use the documented resume path or cleanup script; do not create another untracked stack.

AgentCore environment values cannot contain literal control characters. Public PEM values are stored with escaped newlines and decoded by the app. IAM's create-role and update-trust-policy APIs use different policy parameter names; the deployment script handles that distinction.
